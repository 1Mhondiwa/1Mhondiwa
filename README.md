- Assessment, attendance, timetable, and reporting workflows

Real-time baby care tracking platform built for South African families.

- Row Level Security
- AI-assisted log parsing
- Daily insights
- PDF exports
- Push notifications
- Offline-friendly workflows
- Subscription billing and webhook handling
